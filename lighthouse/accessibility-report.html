Успешно пройденные проверки доступности (WCAG 2.1 AA)

  • ✓
    Buttons have an accessible name — Все кнопки (гамбургер-меню, корзина, модалка, фильтры) имеют явные текстовые метки или атрибуты aria-label.
  • ✓
    Form elements have associated labels — Каждое поле ввода, селект и чекбокс связаны с парным элементом <label for="...">.
  • ✓
    Image elements have [alt] attributes — Все растровые и векторные иллюстрации имеют осмысленные описания alt.
  • ✓
    Background and foreground colors have a sufficient contrast ratio — Контрастность текста превышает порог 4.5:1 для обычного текста и 3:1 для крупных заголовков.
  • ✓
    Heading elements appear in a sequentially-descending order — Строгая семантическая иерархия заголовков: ровно один тег <h1> на страницу, затем логичные <h2> и <h3>.
  • ✓
    [aria-*] attributes match their roles and valid values — Атрибуты aria-expanded, aria-controls, aria-hidden, role="dialog" валидны и динамически переключаются в JS.
  • ✓
    Custom focus outline is visible (:focus-visible) — Настроен четкий кастомный контур фокуса 3px с отступом 3px цвета бренда для пользователей клавиатуры.
  • ✓
    Skip link is present — Ссылка .skip-link позволяет перейти к основному содержимому страницы при нажатии Tab.
  • ✓
    <meta name="viewport"> is present and scalable — Тег viewport присутствует на всех страницах и не блокирует пользовательский зум.
  • ✓
    Interactive controls are keyboard accessible — Мобильное меню и модальное окно полностью управляются с клавиатуры (Tab, Enter, Escape).
